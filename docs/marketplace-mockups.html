Code Review Expert

这个 Skill 会让 AI 助手以专业代码审查员的角色审查你的代码变更。

功能特性：

  • 安全漏洞检测（SQL 注入、XSS、CSRF 等）
  • 性能瓶颈识别
  • 代码风格一致性检查
  • 复杂度分析与重构建议

使用方式：

安装后，使用 /review 命令触发代码审查。
